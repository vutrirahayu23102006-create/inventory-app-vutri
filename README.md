\# Inventory Management System



Aplikasi manajemen inventaris berbasis PHP dan MySQL untuk mengelola data barang, kategori, pemasok, stok, dan laporan inventaris.



\## Fitur



\- Login dan autentikasi pengguna

\- Dashboard inventaris

\- CRUD kategori barang

\- CRUD data produk

\- CRUD data pemasok

\- Pengelolaan stok barang

\- Pencatatan pergerakan stok

\- Laporan inventaris

\- Pencatatan aktivitas aplikasi



\## Teknologi



\- PHP

\- MySQL

\- PDO

\- HTML dan CSS

\- XAMPP



\## Persyaratan



\- XAMPP dengan PHP dan MySQL

\- Browser web

\- Database MySQL



\## Cara Menjalankan



1\. Salin folder project ke direktori `htdocs` XAMPP.

2\. Jalankan Apache dan MySQL melalui XAMPP.

3\. Buat database bernama `inventory-app-vutri` melalui phpMyAdmin.

4\. Siapkan tabel database sesuai struktur yang digunakan project.

5\. Sesuaikan konfigurasi koneksi database di `config/database.php`.

6\. Buka aplikasi melalui browser:



&#x20;  `http://localhost/inventory-app-vutri/`



\## Catatan



Project ini merupakan versi PHP native untuk tugas Pertemuan 4. Versi Laravel akan dikembangkan pada tugas Pertemuan 5.
